# MacroFood — URLs limpas

Estrutura para GitHub Pages no domínio do site:

- Catálogo: `/catalogo/`
- Login: `/login/`
- Administração: `/admin/`

As páginas não dependem umas das outras para montar a URL. Os links usam caminhos relativos explícitos entre as pastas irmãs, evitando o erro `/catalogo/login/admin/`.
