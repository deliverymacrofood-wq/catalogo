# MacroFood — Layout final laranja

Esta versão ajusta o catálogo para o layout de referência aprovado, com foco em:
- identidade laranja dominante;
- cabeçalho claro com barra laranja superior;
- menu de navegação e barra lateral de categorias no desktop;
- catálogo responsivo no celular;
- carrinho em gaveta no desktop e painel inferior no celular;
- carrinho sempre acima de menus e overlays, sem ficar parcialmente escondido;
- textos usando variáveis de tema para evitar texto invisível;
- tema claro/escuro com superfícies, bordas e textos adaptados;
- cinco cartões de benefícios: Entrega rápida; Compras em lojas parceladas em até 3x sem juros; Compre online via Pix; 100% seguro; Retire na loja.

Não é necessário mudar o config.js se as credenciais atuais do Supabase estiverem corretas.
