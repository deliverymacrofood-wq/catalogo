# MacroFood — Layout V12

## O que foi atualizado
- Novo layout visual inspirado na última versão aprovada: laranja dominante, branco, cartões arredondados e foco em ofertas.
- Layout responsivo para computador e celular.
- Categorias organizadas como menu lateral no computador e rolagem horizontal no celular.
- Carrinho flutuante permanece destacado e abre o carrinho ao clicar.
- Produtos mais vendidos, promoções e novidades ganharam hierarquia visual.
- Tema claro e tema escuro para o cliente.
- A escolha do tema fica salva no navegador e continua ao navegar entre catálogo, login, suporte e meus pedidos.
- No tema escuro, o laranja continua sendo a cor principal de destaque.

## Como o cliente troca o tema
No computador, use o botão `Modo escuro`/`Modo claro` no cabeçalho.
No celular, abra o menu de três pontos e use o botão de tema.

Não é necessário alterar o Supabase para o recurso de tema.
